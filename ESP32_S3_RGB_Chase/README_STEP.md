# STEP 旋钮与 RGB 拖尾测试

这是 PID 主机上第一个焊好的 STEP 旋转编码器的独立测试程序。

## 操作

- 开机第一颗 RGB 显示红色。
- 顺时针旋转：一个亮点沿板子外圈顺时针移动，身后留下最多 6 颗逐渐变暗的拖尾。
- 逆时针旋转：亮点逆时针移动，拖尾保留最近实际经过的位置。
- 停止旋转：亮点和拖尾保持原样，没有自动运动或自动淡出。
- 按下一次编码器：整条拖尾切换下一种颜色。长按不会连续切色。
- 颜色顺序：红、橙、黄、绿、青、蓝、紫、粉，再回到红。

按原主机 PCB 核对：STEP_A=GPIO15、STEP_B=GPIO16、STEP_SW=GPIO17，RGB=GPIO47，40 颗。LED 的数据串联顺序在元件面看是逆时针，因此程序已反向映射灯序，让正向逻辑运动为顺时针。编码器 A/B 的实际相位方向仍需转动实物确认。

使用 A/B 双沿中断、Gray 状态转换和 25ms 按键防抖。默认 4 个有效相位跳变移动一颗；部分编码器每格只有 2 个跳变，可用 USB 命令切换。亮度保持原电脑 USB 供电上限 40/255。不初始化 Wi-Fi、蓝牙和其他未焊外设。

## VS Code / PlatformIO

打开本目录的 ESP32_S3_RGB_Chase.code-workspace。

- 默认环境为 `step_encoder`，Ctrl+Shift+B 编译 STEP 程序。
- 终端 -> 运行任务 -> **STEP：烧录** 上传 STEP 程序。
- **STEP：串口监视** 使用 115200 查看旋转、按键和原始 A/B 状态。
- 原来的 20 种灯效代码保留；选 **RGB：烧录** 或环境 `rgb_chase` 即可恢复。
- 烧录前断开其他程序的串口连接。

## USB 命令

普通字符仍原样回显，例如发 `1` 收到 `1`。命令以英文 `!` 开始，以 LF 或 CRLF 结束。

| 命令 | 用途 |
|---|---|
| `!status` 或 `?` | 引脚原始状态、位置、颜色、旋转/按键计数、错误计数和运行时间 |
| `!help` | 帮助 |
| `!reverse on` / `!reverse off` | 编码器实物方向相反时翻转方向 / 恢复默认 |
| `!edges 2` / `!edges 4` | 每格移动所需有效跳变数，默认 4 |
| `!color next` / `!color 1`～`!color 8` | 切色 |
| `!brightness 20` | 亮度 0～40 |
| `!reset` | 位置回到第一颗、恢复红色、清空旋转/按键/模拟计数和拖尾；保持当前亮度、方向和跳变数设置 |
| `!move cw` / `!move ccw` | 软件模拟一步，用于核对灯序；会增加 simulated，不代表物理编码器通过测试 |

旋转或切色后最多每 50ms 输出一条 `STEP_ENCODER` 状态。停止旋转时 `frames` 不应自己持续增加；`cw`/`ccw`/`presses` 只统计物理输入，USB 模拟单独计数。A/B 和按键一般松开为高电平，按键按住为低电平；A/B 的实际静止状态也取决于编码器触点位置。

这个测试固件使用独立的 STEP 命令。原上位机可通过底部输入框发送并查看日志，原 20 种灯效按钮和 RGB_SHOW 状态卡适用于 `rgb_chase` 固件。

设置保存在 RAM，复位后恢复默认。实际顺/逆时针、每格步数和按钮触点是否正常，需要操作板子确认；USB 模拟测试不能替代实物验证。

## 验证记录（2026-10-13）

- STEP 旋转解码、防抖、反转、两/四跳变模式、环形回绕、拖尾保持和颜色切换的本地测试通过。
- 原 20 种 RGB 灯效本地测试通过；`step_encoder` 与 `rgb_chase` 两个环境均编译成功。
- 已通过 COM14 烧录 STEP 固件，写入校验成功，记录见 `validation/step_upload_20261013.txt`。
- 22 项 USB 检查通过，包含回显、顺/逆方向的软件模拟、切色、亮度限制、错误命令恢复、运行时间和静止时不刷新。详细记录见 `validation/step_usb_20261013.json`。
- 45 秒实物观察记录到双向有效步数 86/58、两次按键，颜色由红切到橙、再切到黄；未发生事件队列溢出。使用者确认方向、每格步数和切色都正常，默认方向及每格 4 个跳变设置保持不变。
- 观察期间 710 次原始中断中有 7 次非法 Gray 跳变被丢弃，详细记录见 `validation/step_physical_20261013.json`。本地测试摘要见 `validation/step_native_20261013.txt`。
