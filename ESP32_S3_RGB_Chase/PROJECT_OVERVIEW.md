# 无线 PID 调参器与远程固件烧录工具

更新日期：2026-10-17。已完成本地与 USB 基础，本轮加入主机与从机的 ESP-NOW 参数通信。

项目由主机、从机和目标控制板组成。主机与从机使用 ESP32-S3，用户已将早期从机的 ESP32-C3 更换为与主机相同的型号。目标板为具体型号的 STM32、GD32 等控制板。

PID 计算及实时闭环在目标控制板上执行。主机和从机负责参数操作、通信、反馈数据传输及远程烧录。

规划的数据链路：

```text
电脑 ⇄ USB ⇄ 主机 ⇄ ESP-NOW ⇄ 从机 ⇄ UART ⇄ 目标控制板
                                            └─ BOOT / NRST：控制下载及复位
                                            └─ SWD：后续扩展
```

## 主机功能

| 功能 | 规划用途 | 当前状态 |
|---|---|---|
| P、I、D 三个旋钮 | 调整三个 PID 参数 | 本地与 USB 调节已实现，自动无线同步至从机 RAM；尚未下发目标板 |
| STEP 旋钮 | 调整参数变化步长 | 已实现 0.01、0.10、1.00、10.00 四档步长 |
| OLED | 显示 P/I/D、步长、连接状态、目标板反馈及烧录进度 | 四数据及高亮可用，增加无线在线/同步/从机 ACK 状态；新版显示已现场确认正常，目标反馈及进度待实现 |
| 40 颗 RGB | 旋钮调节反馈、连接/运行/故障状态及灯效 | 已整合整圈渐变流水与同步呼吸、自动彩虹共享拖影及互补色背景，两种模式连续过渡、5 秒自动返回，主机亮度上限 30/255；无线状态映射待实现 |
| LINK LED | 单独指示主从无线连接 | GPIO38，收到有效从机确认后常亮，未连接或失联熄灭；不随 RUN/STOP 或参数调节改变 |
| RUN/STOP 按键 | 向目标板发送启停指令 | GPIO18 本地请求及真实无线从机确认已实现，失联/从机会话变化撤销 RUN；实物启停已现场确认正常，尚未联动目标板 |
| SAVE 按键 | 保存参数 | GPIO21 保存主机 NVS 中的一组 P/I/D/STEP；USB 保存与实际复位恢复通过，实物按钮待确认 |
| USB 电脑连接 | 收发命令、上传参数与固件、接收反馈数据 | 参数读写、状态/事件 JSON、USB 注入曲线数据接口已实现；Windows 现有命令输入框可用，专用 PID 页面及目标固件传输待实现 |
| ESP-NOW | 向从机发送指令和参数，接收反馈与状态 | 已实现两板固定配对、加密单播、完整参数快照、应用层 ACK、重发、失联检测与重启恢复；真实目标数据回传待实现 |

## 从机功能

| 功能 | 用途 | 当前状态 |
|---|---|---|
| 无线与 UART 桥接 | 接收主机指令，经 UART 与目标板交换数据 | 待实现及联调 |
| PID 参数读写 | 下发 P/I/D，回读目标板实际采用的参数 | 已接收主机 P/I/D/STEP 并在 RAM 中镜像和确认；目标板 UART 协议待实现 |
| 数据回传 | 回传速度、角度、循迹误差、目标值及控制输出等 | 待实现；数据由目标板采集或计算 |
| 无线串口透传 | 将目标板日志送到电脑，辅助调试 | 讨论过的扩展，待实现 |
| 状态 RGB | 指示无线连接 | GPIO38：未连接绿色呼吸，连接且收到有效参数快照后绿色常亮；RUN/STOP 不再切换颜色。已替换此前的橙/绿/青/红状态方案，已连接绿色常亮已现场确认，未连接呼吸由自动联调核对 |
| BOOT / NRST 控制 | 远程进入目标板下载模式、复位并启动程序 | F103C8/G431 BOOT/NRST 控制已编写在独立烧录版，实际接线与时序待联调 |
| 无线固件烧录 | 接收固件分块、缓存与校验，再通过目标板 Bootloader 烧写并报告结果 | F103C8/G431 代码、分块重传、SHA256、ROM UART 编程及完整读回已编写，编译及模拟器通过；两板 128 KiB 主动丢包传输通过。实际 G431 接线和擦写待实物联调，日常固件保持原版 |
| 从机 USB | 为从机自身下载固件和本地调试 | COM18 已识别 ESP32-S3、16MB Flash，诊断固件烧录校验、19 项 USB 检查及 30 秒连续运行通过 |

无线烧录第一版流程：电脑提供 G431 `.bin` → 主机经无线分块发送 → 从机内部 RAM 缓存并验证 SHA256 → 显式编程命令控制 BOOT/NRST → 经目标板 ROM UART Bootloader 擦写 → 完整读回并回传结果。成功后留在 ROM，应用启动需另行拉低 BOOT0 并复位。分块编号、确认重传、完整性校验和进度反馈已实现，实际 G431 擦写待实物联调。详见 [STM32 无线烧录适配](../PID_Shared/PIDFlash/README.md)。

## 电脑上位机

已有 Windows 本地程序，可选择串口、发送命令、查看/保存收发日志、控制 RGB 灯效，已做高 DPI 适配。当前灯效控件主要对应 `rgb_chase` 固件，手动输入框可发送其他固件支持的命令。

后续 PID 页面规划包括：参数读写、设备状态、曲线显示和固件烧录。G431 固件传输及烧录已有独立电脑命令行工具，尚未整合进图形界面。主机已提供参数 JSON 及 `telemetry` 数据格式，USB 测试可注入目标值、测量值、误差和控制输出；真实数据仍需从机及目标板接入。曲线可用于观察振荡、超调和稳定过程，服务于电机速度、舵机外部闭环、循迹和仿生船姿态等对象。PID 页面及曲线尚未实现。

## 讨论过的扩展

- SWD / SWO：后续从机硬件设计已考虑相关接口；烧录、变量访问和调试软件尚未实现，能力需按目标芯片验证。
- EXT1～EXT4 和 I2C 扩展接口：用于后续外设或信号扩展，具体用途可再确定。
- 参数组保存、切换与回滚；阶跃响应测试及自动整定。
- 连接心跳、失联状态上报，以及与目标板配合的失联处理。
- 一主多从、固件缓存/选择、从机自身无线升级。
- 电压/电流监测、目标板电源控制、CAN 等曾作为硬件建议讨论；不应据此认为已经全部装板或实现。

## 当前已确认的进度

1. 主机 USB 回显可用。
2. 40 颗 RGB 已点亮，灯效测试通过。
3. P / I / D / STEP 四旋钮的正反转、拖影、停转保持及按下切色，用户确认通过。
4. OLED 已正常显示 `OK`；本机可用配置为 SSD1306 128×64、地址 0x3C、SDA GPIO8、SCL GPIO9。实际控制器型号尚未确认。
5. Windows 上位机已有命令发送、RGB 控制及日志功能。
6. `host_local` 参数校验、USB 读写、启停请求确认、主机 NVS 保存及实际复位恢复通过，共 31 项 USB 检查。
7. 2026-10-16 从机诊断版 `slave_diagnostic` 的 USB 应答、回显、状态查询及连续运行通过；当时未启用无线。UART0 备用口尚未实物测试。
8. 2026-10-17 两板已烧录 `host_wireless` / `slave_wireless`，26 项双板检查通过，含参数同步、真实从机确认、断链撤销 RUN、快速修改、从机实际复位及两端回显；验证结束恢复原 RAM 参数并保持 STOP。
9. 2026-10-17 用户现场确认“旋钮、显示、灯效和启停都正常”：四旋钮、OLED、主机 RGB 及 RUN/STOP 与从机对应状态通过实物验收，SAVE 实物按钮尚待单独确认。
10. 随后按用户要求调整连接指示并烧录两板：主机独立 LINK LED 连接亮、失联灭；从机未连接绿色呼吸、连接绿色常亮。10 项针对性双板检查通过，参数恢复、启停保持 STOP；用户现场确认“两边都正常”，已连接时的主机 LINK LED 常亮与从机绿色常亮通过实物验收；断链灯光由自动联调核对。记录见 `PID_Shared/PIDLink/validation/link_led_result_20261017.json`。

11. STM32 无线烧录适配代码及电脑工具已准备；主从编译、协议核心及 ROM 模拟器测试通过，两板主动丢包环境完成 128 KiB 文件传输和实际 SHA256 校验，重传 576 次。11 项实板传输检查通过；G431 实际擦写尚未执行。测试后恢复日常无线固件。

当前默认及已烧录固件为 `host_wireless` 和 `slave_wireless`，主机 COM14、从机 COM18。主机保留已确认的灯效、旋钮、OLED 和 SAVE；新增参数快照无线同步及从机确认。SAVE 仍保存在主机 NVS，启停确认范围是从机 RAM，不能认定目标板已执行。目标接口 U4/U5 仍关闭。关闭无线的 `host_local` / `slave_diagnostic` 及其他测试环境保留；从机 UART 桥接、目标板参数协议和 PID 曲线页面待实现；G431 无线烧录代码已在独立环境中准备，实物目标联调待完成。
